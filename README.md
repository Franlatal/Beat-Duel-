**ENGLISH**  
Project Name: Beat Duel  
Team Members: Franciszek Latała, Adrian Zając  
Short Project Description: Rhythm game with guitar hero style gameplay where you battle various bosses.  
  
Goal of Project: Make a functioning rhythm game in Godot, with a few fully completed levels.  
Purpose of Project: Entertainment  
Target audience: Fans of rhythm games and people looking for new and unique games  
What does the project enable the user to do: Have fun  
  
Project's most important features: Guitar hero style gameplay, life mechanic, soundtracks segmented into loopable parts  
Technological solutions: Game made in Godot and Moonscraper chart editor software for soundtrack processing.  
Additional functions: Varying difficulty levels for each stage, Local co-op mode  
Expected Final result: A functioning game with at least three complete levels.  
  
Team roles:  
Franciszek Latała - Generalist Programmer (little bit of everything)  
Adrian Zając - Generalist Programmer (little bit of everything)

**POLSKI**  
Nazwa projektu: Beat Duel  
Członkowie zespołu: Franciszek Latała, Adrian Zając  
Krótki opis projektu: Gra rytmiczna z rozgrywką w stylu *Guitar Hero*, w której gracz mierzy się z różnymi bossami.  
  
Cel projektu: Stworzenie w pełni działającej gry rytmicznej w silniku Godot, zawierającej kilka kompletnych poziomów.  
Przeznaczenie projektu: Rozrywka  
Grupa docelowa: Fani gier rytmicznych oraz osoby poszukujące nowych, unikalnych tytułów.

Najważniejsze cechy projektu: Rozgrywka w stylu *Guitar Hero*, mechanika punktów życia, ścieżki dźwiękowe podzielone na sekcje przystosowane do zapętlania.

Dodatkowe funkcje: Zróżnicowane poziomy trudności dla każdego etapu, tryb kooperacji lokalnej.
