# Beat-Duel
Project Name: Beat Duel
Team: Franciszek Latała, Adrian Zając
Short Description: Rythym game with guitar hero style gameplay where you battle various bosses and enemies.

Project's goal: Make a Rythym game in godot engine that matches the guitar hero gameplay with exclusive features of battling bosses and segmented soundtracks.
Project is made for entertainment purposes directed towards fans of rythym games that seek something different.

Plan and scope of the project:

Most important features: Guitar hero style gameplay, segmented soundtracks, life mechanic

Technological solutions: Game made in Godot.

Additional functions: Custom made music, varying difficulty levels for each stage

Final result: A functioning game with three complete levels.
